DAY 3 · DATA & FETCH 06

Fetch로 날씨 카드를 만든다

도시 좌표를 서버에 보내고 JSON 응답을 받는다.
응답 객체의 값을 카드에 배치하면서 요청부터 화면 출력까지 연결한다.

SAFE FLOW

브라우저는 외부 API가 아니라 수업용 서버에 요청한다

OpenWeather 같은 외부 서비스는 API 키로 사용자를 확인한다.
브라우저 JavaScript에 키를 넣으면 개발자 도구와 소스 파일에서 누구나 확인할 수 있다. 

브라우저 ── GET /api/weather ──▶ server.py ──▶ OpenWeather
         ◀── 정리된 JSON ──────          ◀── 외부 응답
  • 로컬 API 서버를 중간에 둔다. 브라우저는 lessonApiUrl()로 8001 포트의 /api/weather에 요청하므로 코드에 외부 API 키를 넣지 않는다.
    server.py가 환경변수의 키를 사용하고 화면에 필요한 필드만 골라 반환한다.
  • 기본값은 mock이다. 키와 인터넷이 없어도 항상 같은 JSON을 받아 DOM 코드를 연습할 수 있다.
    live는 실제 값과 호출 비용이 발생할 수 있으므로 강사가 명시적으로 서버 실행 옵션을 켠 경우에만 사용한다.
  • 프록시는 응답 계약을 단순하게 만든다. 외부 응답 전체를 화면에 넘기지 않고 place, temperature, humidity처럼 수업에서 사용할 속성만 반환한다.
    API 제공자가 바뀌어도 브라우저가 사용할 구조를 일정하게 유지할 수 있다.

GET QUERY

선택한 좌표를 URL의 검색 매개변수로 만든다

도시 선택 값은 37.5665,126.9780처럼 위도와 경도를 쉼표로 묶어 두었다.
split으로 나눈 뒤 URLSearchParams에 넣으면 안전한 쿼리 문자열을 만들 수 있다. 

const [lat, lon] = citySelect.value.split(",");
const params = new URLSearchParams({ lat, lon, mode: modeSelect.value });
const response = await fetch(lessonApiUrl(`/api/weather?${params}`));
  • GET 요청은 주소에 조회 조건을 표현한다. 실제 요청 URL은 http://127.0.0.1:8001/api/weather?lat=37.5665&lon=126.9780&mode=mock 형태이다.
    Network 탭에서 매개변수와 상태 코드를 직접 확인할 수 있다.
  • response.ok를 먼저 검사한다. fetch는 400이나 503 응답도 Response로 받을 수 있으므로 직접 성공 여부를 확인한다.
    실패 응답의 message를 읽어 사용자가 다음 행동을 알 수 있게 표시한다.
  • response.json()은 본문을 JavaScript 객체로 바꾼다. 변환된 객체의 속성을 textContent로 카드에 넣는다.
    데이터 수신과 DOM 출력은 서로 다른 단계이다.

EXAMPLE

도시를 선택해 날씨 결과를 카드로 확인한다

먼저 mock 모드로 요청 흐름과 화면 변화를 확인한다.
live 모드는 서버에 허용 옵션과 API 키가 모두 설정된 수업 환경에서만 성공한다. 

const data = await response.json();
place.textContent = data.place;
temperature.textContent = `${data.temperature} ℃`;
humidity.textContent = `${data.humidity} %`;

서버가 정리한 JSON 보기 
아직 받은 응답이 없다.
  • 요청 중에는 버튼과 선택 상자를 잠근다. 같은 요청이 겹치지 않으며 상태 문구가 로딩 중으로 바뀐다.
    성공과 실패 모두 finally에서 다시 사용할 수 있게 복구한다.
  • 성공하면 카드와 원본 보기가 함께 갱신된다. 카드에는 읽기 쉬운 단위를 붙이고 details에는 서버가 반환한 객체를 들여쓰기한 JSON으로 표시한다.
    둘은 같은 데이터를 서로 다른 목적에 맞춰 표현한 결과이다.
  • 오류이면 이전 카드를 숨긴다. 이전 성공 결과가 새 요청의 결과처럼 남지 않게 하고 서버의 안전한 안내만 표시한다.
    API 키나 외부 서비스의 전체 오류 응답은 브라우저로 전달하지 않는다.
