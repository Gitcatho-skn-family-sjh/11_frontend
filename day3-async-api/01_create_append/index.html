입력값 세 개를 읽어 하나의 카드 구조로 바꾸고, 삭제 버튼의 클릭 이벤트로 다시 제거한다.
요소 생성·내용 설정·부모 자식 연결·이벤트 처리로 이어지는 DOM 작업의 전체 흐름을 확인한다.

DATA → DOM TREE

문자열 세 개가 동작하는 카드 한 장이 되는 과정

폼을 제출하면 이름·분류·설명은 문자열로 읽힌다.
JavaScript는 필요한 요소 객체를 각각 만들어 DOM 트리로 연결하고, 버튼에는 현재 카드를 삭제하는 동작을 등록한다.

  1. 입력: input, select, textarea의 value를 읽고 앞뒤 공백을 제거한다.
    이름이나 설명이 비어 있으면 카드를 만들지 않고 입력 위치로 포커스를 돌린다.
  2. 생성: article, h3, p, span, button을 각각 만든다.
    createElement 직후의 요소는 메모리에만 존재하며 아직 화면에는 나타나지 않는다.
  3. 설정: 사용자 입력은 textContent로 넣고, 꾸밈은 classList, 식별 정보는 dataset으로 설정한다.
    표시할 내용과 프로그램이 사용할 정보를 서로 다른 속성에 보관한다.
  4. 연결: 작은 요소를 article에 붙인 다음 완성된 article을 목록에 붙인다.
    마지막 append가 실행되어야 카드가 현재 문서의 DOM 트리에 들어간다.
  5. 동작: 삭제 버튼에서 click 이벤트가 발생하면 card.remove()를 실행한다.
    remove는 해당 요소와 그 안의 모든 자식 요소를 DOM 트리에서 함께 제거한다.
section#service-list
└─ article.service-card  data-service-id="1"
   ├─ span.service-badge
   ├─ h3
   ├─ p
   └─ button             data-action="delete"

SAFE TEXT & METADATA

보이는 글자와 동작에 필요한 데이터를 구분한다

  • textContent: 사용자 입력을 HTML이 아닌 글자로 표시한다.
    <img>처럼 생긴 값을 입력해도 새 태그로 해석되지 않는다.
  • classList: CSS가 찾을 class를 추가한다.
    내용과 스타일의 역할을 분리할 수 있다.
  • dataset: data-service-id="1"은 JavaScript에서 element.dataset.serviceId로 읽는다.
    요소가 어떤 데이터를 가리키는지 기록할 때 사용한다.
  • append: 여러 자식을 쉼표로 전달하면 순서대로 부모의 마지막에 붙는다.
    배지 → 제목 → 설명 → 삭제 버튼 순서가 화면 순서가 된다.
  • remove: 삭제할 요소에서 호출하면 그 요소를 DOM 트리에서 꺼낸다.
    화면에서 사라진 카드는 더 이상 문서의 요소로 선택되지 않는다.

EXAMPLE

완성 코드를 따라 서비스 카드 생성·삭제 흐름을 연결한다

입력 → 검증 → 생성 → 설정 → 연결 → 이벤트JavaScript
const serviceForm = document.querySelector("#service-form");
const serviceNameInput = document.querySelector("#service-name");
const serviceCategorySelect = document.querySelector("#service-category");
const serviceDescriptionInput = document.querySelector("#service-description");
const serviceList = document.querySelector("#service-list");
const serviceMessage = document.querySelector("#service-message");
let nextServiceId = 1;

function addServiceCard(event) {
  let serviceName = "";
  let category = "";
  let description = "";

  // ***** TODO 1. 기본 제출을 막고 폼 입력값 세 개 읽기 *****
  event.preventDefault();
  serviceName = serviceNameInput.value.trim();
  category = serviceCategorySelect.value;
  description = serviceDescriptionInput.value.trim();
  // **************************************************************

  if (serviceName === "" || description === "") {
    serviceMessage.textContent = "서비스 이름과 설명을 모두 입력한다.";
    (serviceName === "" ? serviceNameInput : serviceDescriptionInput).focus();
    return;
  }

  let card = null;
  let badge = null;
  let title = null;
  let descriptionText = null;
  let deleteButton = null;

  // ***** TODO 2. 카드에 필요한 다섯 요소 만들기 *****
  card = document.createElement("article");
  badge = document.createElement("span");
  title = document.createElement("h3");
  descriptionText = document.createElement("p");
  deleteButton = document.createElement("button");
  // **************************************************************

  if (!card || !badge || !title || !descriptionText || !deleteButton) return;

  // ***** TODO 3. 사용자 입력을 각 요소의 textContent에 넣기 *****
  badge.textContent = category;
  title.textContent = serviceName;
  descriptionText.textContent = description;
  deleteButton.textContent = "카드 삭제";
  // **************************************************************

  // ***** TODO 4. class와 data 속성으로 요소의 역할 기록하기 *****
  card.classList.add("service-card");
  badge.classList.add("service-badge");
  card.dataset.serviceId = String(nextServiceId);
  deleteButton.classList.add("service-delete-button");
  deleteButton.dataset.action = "delete";
  deleteButton.type = "button";
  // **************************************************************

  // ***** TODO 5. 자식 요소를 카드에 붙이고 카드를 목록에 붙이기 *****
  card.append(badge, title, descriptionText, deleteButton);
  serviceList.append(card);
  // **************************************************************

  // ***** TODO 6. 삭제 버튼을 누르면 현재 카드 제거하기 *****
  deleteButton.addEventListener("click", function () {
    card.remove();
    serviceMessage.textContent = serviceName + " 카드를 삭제했다.";
    serviceNameInput.focus();
  });
  // **************************************************************

  nextServiceId += 1;
  serviceForm.reset();
  serviceMessage.textContent = serviceName + " 카드를 추가했다.";
  serviceNameInput.focus();
}

// ***** TODO 7. form의 submit 이벤트에 addServiceCard 함수 등록하기 *****
serviceForm.addEventListener("submit", addServiceCard);
// **************************************************************

폼을 제출하면 아래에 카드가 추가된다.
