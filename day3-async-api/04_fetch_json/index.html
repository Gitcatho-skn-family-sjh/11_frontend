AJAX와 Fetch로 필요한 부분만 바꾸기

페이지 전체를 새로 열지 않고 서버에서 필요한 데이터만 받는다.
텍스트와 JSON을 각각 읽어 문단과 표로 출력한다.

AJAX

AJAX는 페이지 일부를 갱신하는 웹 개발 기법이다

AJAX(Asynchronous JavaScript and XML)는 전체 페이지 새로고침 없이 비동기 HTTP 요청으로 필요한 데이터만 받고, JavaScript로 DOM 일부를 바꾸는 기법이다.
이름에는 XML이 있지만 현재는 다루기 쉬운 JSON을 자주 사용한다.

  • AJAX는 상위 개념이다. 사용자가 검색 버튼을 누른 뒤 현재 화면을 유지한 채 결과 영역만 바꾸는 동작 전체를 뜻한다.
    특정 함수나 라이브러리 하나의 이름이 아니다.
  • Fetch는 AJAX를 구현하는 현대 브라우저 API이다. 별도 설치 없이 fetch()로 HTTP 요청을 보낼 수 있다.
    응답은 Promise로 오므로 앞 단원에서 배운 await를 사용한다.
  • DOM 갱신까지 연결해야 화면에 보인다. 데이터를 받기만 해서는 페이지가 바뀌지 않는다.
    textContent, createElement, append로 원하는 영역을 갱신한다.

FETCH FLOW

요청부터 DOM까지 네 단계로 읽기

  • fetch(url)
    기본값인 GET 방식으로 주소에 요청한다.
  • Response와 response.ok
    응답 상태를 받고 HTTP 성공 여부를 검사한다.
  • response.text() 또는 response.json()
    본문을 목적에 맞는 방식으로 한 번만 읽는다.
  • DOM 출력
    읽은 문자열이나 객체 배열로 현재 페이지의 일부를 바꾼다. 
const response = await fetch(lessonApiUrl("/api/demo/json"));

if (!response.ok) {
  throw new Error(`HTTP ${response.status}`);
}

const data = await response.json();
renderDemoRows(tableBody, data);

404도 Response를 받을 수 있다

fetch()는 서버가 404 응답을 보내도 Response 객체를 정상적으로 반환한다.
그래서 response.ok를 직접 검사해 오류 처리 흐름으로 보내야 한다.

TEXT / JSON

본문은 사용할 형태를 정한 뒤 한 번 읽는다

response.text()

응답 본문을 하나의 문자열로 받는다.

안내 문장, CSV 원문, HTML 원문처럼 텍스트 그대로 사용할 때 적합하다.

response.json()

JSON 텍스트를 JavaScript 객체나 배열로 해석한다.

속성을 읽고 반복하여 표나 카드로 만들 때 적합하다.

같은 Response에서 text()를 호출한 뒤 다시 json()을 호출하지 않는다.
응답 본문 스트림은 한 번 읽으면 소비되므로 필요한 방식 하나를 선택한다.

LOCAL SERVER

Live Server의 페이지에서 Python API 서버로 요청하기

fetch()는 브라우저에서 실행되지만 요청을 받고 응답을 보내는 프로그램도 필요하다.
HTML·CSS·JavaScript는 VS Code Live Server가 5500 포트로 열고, server.py는 8001 포트에서 실습용 API 응답을 돌려준다.

Django·FastAPI·Flask나 별도 pip 패키지를 사용한 서버가 아니다.

Python 3의 http.server를 중심으로 구현했다.

ThreadingHTTPServer가 요청을 받고, SimpleHTTPRequestHandler가 정적 파일을 전달하며, json과 urllib가 JSON 처리와 선택적인 외부 요청을 담당한다.

포트가 다르면 서로 다른 출처이다.

http://127.0.0.1:5500과 http://127.0.0.1:8001은 포트가 달라 브라우저가 교차 출처 요청으로 판단한다.

server.py는 Live Server의 두 주소만 CORS로 허용하고, JSON POST 전에 오는 OPTIONS 사전 요청도 처리한다.

실행, 종료 방법

  • 터미널 위치를 확인한다.
    편집기에서 배포받은 day3-async-api 폴더를 터미널로 연다.
  • 로컬 서버를 시작한다.
    아래 명령을 실행한다. Python 3만 필요하며 npm·pip 설치는 필요하지 않다.
    day3-async-api 폴더의 터미널Python 
    python3 server.py --port 8001
  • HTML은 Live Server로 연다.
    VS Code에서 index.html을 우클릭해 Open with Live Server를 선택하고 주소가 http://127.0.0.1:5500 또는 http://localhost:5500으로 시작하는지 확인한다.
  • 실습이 끝나면 종료한다.
    서버를 실행한 터미널에서 Ctrl+C를 누른다.

두 서버의 역할을 구분한다

Live Server 5500은 HTML·CSS·JavaScript 파일을 전달한다.
Python 서버 8001은 /api/... 요청을 받고 text 또는 JSON을 반환한다. 제공 함수 lessonApiUrl()이 상대 API 경로 앞에 8001 서버 주소를 붙인다.

  • /api/demo/text는 짧은 일반 텍스트를 응답한다.
    response.text()로 읽어 하나의 문단에 출력한다.
  • /api/demo/json은 객체 배열이 담긴 JSON을 응답한다.
    response.json()으로 읽어 여러 표 행을 만든다.
  • /api/demo/missing은 존재하지 않아 404를 응답한다.
    response.ok 검사가 왜 필요한지 관찰한다.

MDN: AJAX와 MDN: Fetch 사용하기에서 같은 흐름을 확인할 수 있다.

Text와 JSON 응답을 서로 다른 DOM으로 출력하기

async function loadResource(endpoint, format) {
  const response = await fetch(endpoint);

  if (!response.ok) {
    throw new Error(`HTTP ${response.status}`);
  }

  const data =
    format === "text"
      ? await response.text()
      : await response.json();
}

jsonButton.addEventListener("click", function () {
  loadResource(lessonApiUrl("/api/demo/json"), "json");
});
