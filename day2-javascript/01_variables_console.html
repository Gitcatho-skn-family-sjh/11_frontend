JAVASCRIPT 01

변수에 값을 저장하고 실행 결과를 확인한다

JavaScript 파일을 실행하고, 이름에 저장한 값이 언제 바뀌는지 읽는다.
선언·대입·출력의 차이를 익히면 이후 자료형과 조건문을 따라가기 쉬워진다.

Node.js · 브라우저const · let주석 · 오류

JAVASCRIPT

Node.js는 작은 JavaScript 파일을 실행하는 도구이다

JavaScript는 브라우저뿐 아니라 Node.js에서도 실행된다.
지금은 Node 서버를 만드는 것이 아니라, 값 처리 코드의 결과를 터미널에서 확인하는 데만 사용한다.

  • 터미널: 현재 폴더를 day2-javascript로 맞추고 node 01_variables_console.js를 실행한다.
    Node.js 설치가 필요하지만 npm 패키지나 별도 서버는 필요하지 않다.
  • 브라우저: 같은 이름의 HTML을 열고 개발자 도구의 Console을 확인한다.
    HTML에 연결된 01_variables_console.js가 실행되므로, 저장한 뒤 페이지를 새로 고쳐 결과를 다시 볼 수 있다.
  • 같은 문법, 다른 제공 기능: console.log는 두 환경에서 사용할 수 있지만, 웹페이지를 다루는 document는 브라우저가 제공한다.
    먼저 값과 실행 순서를 익힌 뒤 DOM에서 화면을 직접 바꾼다.
  • 아래 출력 영역: 정상 실행 결과는 비교 기준이며 자동 실행 화면이 아니다.
    실제 결과는 터미널 또는 Console에서 읽는다. 브라우저에서는 값의 종류에 따라 색이나 펼침 표시가 다를 수 있다.

JAVASCRIPT

변수는 다시 사용할 값에 붙인 이름이다

변수를 선언하면 코드에서 사용할 이름을 만든다.
그 이름에 값을 대입하고, 필요한 위치에서 이름을 읽어 현재 값을 사용한다.

  • const cafeName = "느린 오후 카페";에서 const는 선언 방식, cafeName은 변수 이름, =는 대입, 따옴표 안은 저장할 문자열이다.
    끝의 세미콜론은 문장을 마무리한다.
  • const: 같은 이름에 다른 값을 다시 대입하지 않을 때 사용한다.
    선언할 때 초기값이 필요하며, 메뉴명이나 기준값처럼 바꾸지 않는 이름에 적합하다.
  • let: 값이 바뀔 수 있는 이름을 선언한다.
    let quantity = 2;로 선언한 뒤 quantity = 3;처럼 다시 대입한다. 재대입할 때 let을 또 쓰지 않는다.
  • 출력은 별도 작업: 변수 선언만으로 Console에 값이 보이지는 않는다.
    console.log()의 괄호 안에 값을 넣어야 그 시점의 값이 출력된다.

EXAMPLE

고정된 이름을 선언하고 출력한다

카페 이름은 고정된 문자열로 저장하고, 주문 번호는 숫자로 저장한다.
각 값은 출력문을 만났을 때 Console에 나타난다.

  • 문자열은 따옴표로 감싸고 숫자는 따옴표 없이 적는다.
    다음 자료형 단원에서 두 값이 계산과 비교에서 어떻게 달라지는지 확인한다.
  • console.log("주문 번호:", orderNumber)의 쉼표는 여러 값을 한 줄에 출력하도록 구분한다.
    설명 문장과 값을 함께 출력하면 어떤 변수를 확인하는지 알 수 있다.
01_variables_console.jsEXAMPLE
// ***** TODO 1. const로 cafeName을 선언하고 카페 이름 출력하기 *****
const cafeName = "느린 오후 카페";
console.log("카페 이름:", cafeName);
// **************************************************************
const orderNumber = 17;
console.log("주문 번호:", orderNumber);

정상 실행 결과

카페 이름: 느린 오후 카페
주문 번호: 17

카페 이름과 주문 번호가 코드 순서대로 출력된다.
문자열과 숫자는 서로 다른 종류의 값이지만, Console에서 둘 다 확인할 수 있다.

EXAMPLE

let으로 저장한 수량을 다시 대입한다

수량을 2로 시작한 뒤 주문 변경을 반영해 3으로 바꾼다.
출력문은 앞에서 마지막으로 대입된 값을 읽는다.

  • quantity = 3;은 새 변수를 만드는 문장이 아니라 기존 변수의 값을 바꾸는 문장이다.
    같은 범위에서 let quantity를 다시 선언하면 중복 선언 오류가 발생한다.
  • const savedQuantity = quantity;는 그 시점의 숫자를 저장한다.
    나중에 quantity를 4로 바꿔도 savedQuantity가 자동으로 따라 바뀌지는 않는다.
01_variables_console.jsEXAMPLE
let quantity = 2;
console.log("변경 전 수량:", quantity);
// ***** TODO 2. quantity에 새 수량 3을 대입하기 *****
quantity = 3;
// **************************************************************
console.log("변경 후 수량:", quantity);
const savedQuantity = quantity;
quantity = 4;
console.log("현재 수량:", quantity);
console.log("앞서 저장한 수량:", savedQuantity);

정상 실행 결과

변경 전 수량: 2
변경 후 수량: 3
현재 수량: 4
앞서 저장한 수량: 3

수량은 2 → 3 → 4로 바뀌지만, 중간에 저장한 숫자는 3으로 남는다.
변수는 다른 변수의 변경을 자동으로 추적하는 수식이 아니다.

EXAMPLE

주석은 설명을 남기고, 출력문은 실행 상태를 보여 준다

주석은 코드를 읽는 사람을 위한 설명이며 실행되지 않는다.
한 줄 주석은 //, 여러 줄 주석은 /*와 */로 감싼다.

  • 주석에는 코드의 목적이나 주의할 조건을 적는다.
    console.log는 실제로 실행되며 값이나 실행 위치를 관찰할 때 사용한다.
  • 값을 선언만 한 let message;의 초기값은 undefined이다.
    아래에서는 빈 문자열을 먼저 넣고, 안내 문장을 대입한 후 출력한다.
01_variables_console.jsEXAMPLE
// 이 문장은 실행되지 않는 한 줄 주석이다.
let message = "";
/* 안내 문장을 먼저 만들고,
   그 문장을 출력하여 현재 상태를 확인한다. */
// ***** TODO 3. message에 주문 확인 완료 안내 문자열 대입하기 *****
message = "주문 확인 완료";
// **************************************************************
console.log("처리 상태:", message);
console.log("마지막 줄까지 실행했습니다.");

정상 실행 결과

처리 상태: 주문 확인 완료
마지막 줄까지 실행했습니다.

주석 내용은 출력되지 않고 두 console.log 문장만 출력된다.
마지막 줄이 보이면 코드가 해당 위치까지 실행된 것이다.

JAVASCRIPT

이름과 실행 순서를 확인하면 기본 오류를 찾을 수 있다

오류 메시지는 실행이 멈춘 파일과 줄을 알려 준다.
먼저 그 위치를 확인하고 따옴표·괄호·변수 이름을 점검한다.

  • 이름 규칙: 이름은 대소문자를 구분하고 숫자로 시작할 수 없다.
    orderNumber와 ordernumber는 다른 이름이다. 역할이 드러나는 이름을 사용하면 값의 흐름을 읽기 쉽다.
  • SyntaxError: 따옴표나 괄호가 닫혔는지, 같은 범위에서 let·const 이름을 중복 선언하지 않았는지 확인한다.
    ReferenceError: 이름에 오타가 있거나 선언문이 실행되기 전에 사용하지 않았는지 확인한다.
  • const 재대입: 고정한 이름에 새 값을 대입하면 TypeError가 발생한다.
    실제로 바뀌어야 하는 값만 let으로 선언한다. 객체 내부의 값 변경과 재대입의 차이는 객체 단원에서 다룬다.
  • 재실행: 편집기에서 수정한 뒤 저장하고 Node 명령을 다시 실행하거나 페이지를 새로 고친다.
    파일을 찾지 못하면 코드보다 먼저 현재 폴더와 파일명을 확인한다.
