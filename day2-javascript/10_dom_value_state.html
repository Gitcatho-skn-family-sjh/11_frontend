VALUE & TEXT

입력칸의 현재 값과 일반 요소의 글자는 읽는 자리가 다르다

input의 현재 입력값은 value에 있고, 문단에 적힌 글자는 textContent에 있다.
먼저 요소를 찾고, 어떤 종류의 값을 읽거나 바꿀지에 따라 프로퍼티를 선택한다.

  • nameInput.value: 사용자가 입력칸에 현재 입력한 문자열을 읽는다.
    type="number"인 입력칸도 value로 읽으면 문자열이다.
  • nameInput.textContent: input의 자식 텍스트를 읽는다.
    input은 자식 텍스트를 넣는 요소가 아니므로 이 값으로 사용자가 입력한 이름을 얻을 수 없다.
  • greeting.textContent: 인사 문단의 글자를 읽거나 바꾼다.
    대입하면 기존 글자를 새 문자열로 교체한다. 출력 영역에 자식 요소가 있다면 그 내용도 함께 교체된다.
  • HTML의 value 속성은 초기값이다.
    사용자가 바꾼 현재 값은 .value로 읽는다. getAttribute("value")로 현재 입력을 대신 읽지 않는다.

TRIM

앞뒤 공백을 정리한 반환값을 사용한다

trim()은 문자열 앞뒤의 공백을 제거한 새 문자열을 반환한다.
입력값을 읽은 뒤 정리한 결과를 변수에 담고, 그 변수로 화면에 표시할 문장을 만든다.

  • " 민지 ".trim()은 "민지"를 반환한다.
    중간 공백은 제거하지 않으므로 "김 민지"는 그대로 유지된다.
  • rawName.trim()을 호출해도 rawName 자체나 입력칸의 value는 바뀌지 않는다.
    반환값을 name에 저장했을 때 name만 공백이 제거된 문자열을 가진다.
  • " "처럼 공백만 있는 입력은 trim 뒤 ""가 된다.
    빈 문자열인지 검사할 때는 공백 정리를 먼저 해야 사용자가 아무 내용도 입력하지 않은 경우를 함께 잡을 수 있다.

EXAMPLE

최초 입력값으로 인사 문장을 만든다

현재 값 → 공백 정리 → 문장 출력JavaScript
const nameInput = document.querySelector("#name-input");
const greeting = document.querySelector("#greeting");
let rawName = "";
let name = "";

// 이 파일은 페이지를 열 때 한 번 실행된다. 아직 이벤트를 등록하지 않는다.
// ***** TODO 1. 입력칸의 현재 value를 읽고 앞뒤 공백을 제거한 name 만들기 *****
rawName = nameInput.value;
name = rawName.trim();
// **************************************************************

if (name !== "") {
  // ***** TODO 2. name을 포함한 인사 문장을 greeting의 textContent에 넣기 *****
  greeting.textContent = name + "님, 반갑습니다.";
  // **************************************************************
}

아직 인사 문장을 만들지 않았다.

초기값은 " 민지 "이고 정상 출력은 민지님, 반갑습니다.이다.
입력칸에는 원래 공백이 남아 있어도 출력에 사용한 name은 공백이 제거된 값이다.

textContent는 문자열을 HTML로 해석하지 않는다.
<b>민지</b>를 대입하면 굵은 글자가 아니라 꺾쇠를 포함한 문자 그대로 나타난다.

NUMBER

계산에 사용할 입력은 숫자로 변환한다

화면에 숫자가 보여도 value는 문자열이다.
Number("2")는 문자열 "2"를 숫자 2로 바꾸므로 이후 산술 계산에 사용할 수 있다.

  • quantityInput.value + 1에서 value가 "2"이면 결과는 문자열 "21"이다.
    Number(quantityInput.value) + 1의 결과는 숫자 3이다.
  • 입력 요소의 종류와 JavaScript 값의 타입을 구분한다.
    type="number"는 브라우저의 숫자 입력 UI와 제약을 정하고, Number는 읽어 온 문자열을 숫자 값으로 바꾼다.
  • 변환만으로 올바른 입력인지 보장되지는 않는다.
    Number("")는 0이고 Number("abc")는 NaN이다. 실제 제출에서는 빈 입력과 허용 범위를 별도로 검사해야 한다.

EXAMPLE

수량 문자열을 가격 계산에 사용한다

"2" → 2 → 6000JavaScript
const quantityInput = document.querySelector("#quantity-input");
const totalPrice = document.querySelector("#total-price");
const unitPrice = 3000;

// value의 "2"를 숫자 2로 바꾸어 가격 계산에 사용한다.
// ***** TODO 3. 현재 수량을 Number로 변환하고 총 가격 문장 표시하기 *****
const quantity = Number(quantityInput.value);
const total = unitPrice * quantity;
totalPrice.textContent = quantity + "장 × " + unitPrice + "원 = " + total + "원";
// **************************************************************

아직 가격을 계산하지 않았다.

초기 수량 "2"를 숫자로 바꾼 뒤 3000과 곱하므로 2장 × 3000원 = 6000원이 표시된다.
이 예제는 HTML의 정해진 초기값을 한 번 계산하는 단계이며, 입력 변경이나 제출 검증은 아직 연결하지 않았다.

CLASS & STATE

글자·모양·버튼 사용 가능 여부는 각각 바꾼다

모양은 CSS에 정의하고 JavaScript는 class 이름으로 상태를 선택할 수 있다.
요소에 연결한 작은 데이터는 dataset으로 읽고, 버튼을 사용할 수 있는지는 disabled로 제어한다.

  • classList.add("important"): 기존 class를 유지하면서 important를 추가한다.
    이미 있으면 중복으로 붙지 않는다. remove("important")는 그 class만 제거하고 contains("important")는 존재 여부를 true/false로 반환한다.
  • data-level="필수": HTML 요소에 안내 수준을 연결한다.
    JavaScript에서는 notice.dataset.level로 읽는다. data-item-id는 dataset.itemId처럼 이름이 연결된다.
  • dataset 값은 문자열이다.
    data-count="3"도 "3"으로 읽는다. 이 값으로 계산하려면 입력값과 마찬가지로 Number 변환이 필요하다.
  • button.disabled = true는 비활성, false는 활성 상태이다.
    setAttribute("disabled", "false")는 속성이 남아 있으므로 여전히 비활성이다. 현재 상태를 바꿀 때는 DOM 프로퍼티에 불리언을 대입한다.
  • setAttribute("aria-label", "..."): 속성 이름과 문자열 값을 지정한다.
    aria-label은 보조 기술이 읽는 요소의 이름이다. 화면에 보이는 본문 문장을 바꾸는 textContent와 목적이 다르다.

EXAMPLE

안내를 강조하고 확인 버튼을 활성화한다

데이터 읽기 · class 추가 · 상태 변경JavaScript
const notice = document.querySelector("#notice");
const confirmButton = document.querySelector("#confirm-notice");
const state = document.querySelector("#state");
let level = "";

// ***** TODO 4. dataset의 안내 수준을 읽고 important class와 aria-label 설정하기 *****
level = notice.dataset.level;
notice.classList.add("important");
notice.setAttribute("aria-label", "준비물 안내 " + level);
// **************************************************************

// disabled에는 문자열 "false"가 아니라 불리언 false를 대입한다.
// ***** TODO 5. confirmButton의 disabled를 false로 바꾸어 버튼 활성화하기 *****
confirmButton.disabled = false;
// **************************************************************

if (level !== "") {
  state.textContent = level + " 안내를 강조했다. 버튼의 disabled 값: " + confirmButton.disabled;
}

준비물 안내

노트와 필기구를 준비해 주세요.

기본 안내 상태이다.

  • dataset에서 읽은 "필수"는 aria-label과 상태 문장에 사용된다.
    dataset을 읽는 것만으로 색이 바뀌지 않으며, important class가 추가될 때 공통 CSS의 강조 스타일이 적용된다.
  • HTML에서는 비활성으로 시작한 버튼이 false 대입 후 활성화된다.
    지금은 click 이벤트가 없으므로 버튼을 눌러도 별도의 동작이 실행되지 않는다.
  • 세 예제 모두 페이지가 열릴 때 한 번만 실행된다.
    입력칸의 값을 바꿔도 인사나 가격이 저절로 다시 계산되지는 않는다. 다음 주제에서 input과 click 이벤트를 연결해 필요한 순간에 다시 실행한다.
