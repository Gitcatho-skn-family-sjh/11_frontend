DOM을 선택하고 화면 글자 바꾸기

HTML을 읽은 뒤 요소를 찾고, 선택한 요소의 글자를 읽거나 바꾼다.
브라우저 문서, 실행 시점, 선택 결과를 나누어 화면 변경의 출발점을 만든다.

HTML TO DOM

브라우저가 HTML을 읽으면 요소 객체가 만들어진다

DOM(Document Object Model)은 브라우저가 HTML을 읽고 만든 문서의 객체 표현이다.
JavaScript는 HTML 파일의 글자를 직접 고치는 대신 현재 DOM에서 제목이나 목록 요소를 찾아 화면을 바꾼다.

  • document는 현재 브라우저 문서를 가리킨다.
    문서 전체에서 요소를 찾는 출발점이다. 앞에서 문법을 실행한 Node에는 브라우저의 document가 기본 제공되지 않으므로 이 파일은 HTML을 브라우저로 열어 실행한다.
  • 바로 한 단계 아래는 자식, 그 아래까지 포함하면 후손이다.
    section 안의 ul은 자식이고, ul 안의 li는 section의 후손이다. 같은 ul을 부모로 공유하는 li들은 형제이다.
  • 현재 DOM을 바꾸어도 원본 HTML 파일이 저장되지는 않는다.
    JavaScript로 바꾼 문장은 개발자 도구의 Elements에서 확인할 수 있다. 페이지를 새로 열면 HTML을 다시 읽고 JavaScript도 다시 실행한다.
section#classroom
├─ h3
└─ ul
   ├─ li.lesson
   ├─ li.lesson
   └─ li.lesson

SCRIPT & DEFER

HTML을 읽은 뒤에 요소를 찾도록 연결한다

script의 src는 실행할 JavaScript 파일의 경로이다.
외부 스크립트에 defer를 붙이면 브라우저는 HTML을 읽는 동안 파일을 가져오고, HTML 해석을 마친 뒤 실행한다.

<head>
  <script src="09_dom_select.js" defer></script>
</head>
  • 요소가 만들어진 다음 찾을 수 있도록 실행 시점을 맞춘다.
    head에서 defer 없이 바로 실행하면 아직 읽지 않은 body의 요소를 찾지 못할 수 있다.
  • defer는 선택자 오류를 고쳐 주는 옵션이 아니다.
    실행 시점이 맞아도 id나 class 철자가 틀리면 요소를 찾지 못한다. 파일 경로 오류는 개발자 도구의 Console과 Network에서 확인한다.
  • 현재 파일은 페이지를 열 때 한 번 실행된다.
    앞으로 버튼과 입력에 반응하게 하려면 실행할 함수를 이벤트에 연결해야 한다.

SELECT & TEXT

요소 선택과 글자 읽기는 서로 다른 작업이다

querySelector는 CSS 선택자에 맞는 첫 번째 요소 하나를 반환한다.
그 결과는 문자열이 아니라 요소 객체이므로 요소 안의 글자가 필요할 때 textContent를 읽는다.

  • document.querySelector("#classroom"): 문서에서 id가 classroom인 요소를 찾는다.
    #을 빼면 id가 아니라 태그 이름을 찾는 선택자가 된다.
  • classroom.querySelector(".lesson"): classroom의 후손 중 class가 lesson인 첫 요소를 찾는다.
    문서 전체가 아니라 선택한 영역 안에서만 검색하므로 바깥의 같은 class는 포함하지 않는다.
  • firstLesson.textContent: 선택한 요소 안의 글자를 문자열로 읽는다.
    result.textContent = "새 문장"처럼 대입하면 출력 요소의 기존 글자가 교체된다.
  • 찾는 요소가 없으면 null을 반환한다.
    null은 요소 객체가 아니므로 null.textContent를 읽을 수 없다. 속성을 사용하기 전에 !== null로 확인한다.

EXAMPLE

부모 영역 안에서 첫 수업을 찾아 출력한다

요소 선택 → 글자 읽기 → 문장 출력JavaScript
const result = document.querySelector("#result");
let classroom = null;

// ***** TODO 1. #classroom 요소를 찾아 classroom에 저장하기 *****
classroom = document.querySelector("#classroom");
// **************************************************************

// 선택한 부모 안에서 다시 찾으면 검색 범위가 그 영역으로 좁아진다.
if (classroom !== null) {
  const firstLesson = classroom.querySelector(".lesson");
  if (firstLesson !== null) {
    // ***** TODO 2. 첫 수업의 글자를 읽어 result에 안내 문장 표시하기 *****
    result.textContent = "첫 수업: " + firstLesson.textContent;
    // **************************************************************
  }
}

아직 첫 수업을 선택하지 않았다.

선택 결과는 첫 번째 li 요소이고, 그 요소의 textContent는 "HTML 구조"이다.
정상 출력은 첫 수업: HTML 구조이다. 목록의 나머지 항목은 지워지거나 자동으로 선택되지 않는다.

EXAMPLE

일치하는 첫 요소와 없는 요소를 구분한다

"#book-list .book"의 공백은 후손 관계를 나타낸다.
같은 class가 여러 개여도 querySelector는 첫 요소 하나만 반환하고, 일치하는 요소가 하나도 없으면 null을 반환한다.

첫 도서 선택과 null 분기JavaScript
const selectedBook = document.querySelector("#selected-book");
const missingResult = document.querySelector("#missing-result");
let firstBook = null;

// ***** TODO 3. #book-list 안의 첫 .book 요소를 firstBook에 저장하기 *****
firstBook = document.querySelector("#book-list .book");
// **************************************************************

// 요소 객체가 있을 때만 그 안의 글자를 읽는다.
if (firstBook !== null) {
  // ***** TODO 4. firstBook의 글자를 읽어 선택한 도서 문장으로 출력하기 *****
  const bookTitle = firstBook.textContent;
  selectedBook.textContent = "선택한 첫 도서: " + bookTitle;
  // **************************************************************
}

// ***** TODO 5. 없는 .not-found 요소를 찾고 null이면 안내 표시하기 *****
const missingBook = document.querySelector("#book-list .not-found");
if (missingBook === null) {
  missingResult.textContent = ".not-found에 해당하는 요소가 없어 null을 반환했다.";
}
// **************************************************************

책장

  • 자바스크립트 첫걸음
  • 웹의 구조
  • 읽기 좋은 코드

아직 도서를 선택하지 않았다.

  • 정상 결과는 선택한 첫 도서: 자바스크립트 첫걸음이다.
    변수 firstBook은 li 요소이고, bookTitle은 그 안에서 읽은 문자열이다.
  • .not-found는 실제 HTML에 없는 class이다.
    의도적으로 없는 요소를 찾아도 null을 확인했으므로 오류 없이 안내를 표시한다.
  • 요소가 없는 것과 선택자 문법이 잘못된 것은 다르다.
    "["처럼 CSS 문법 자체가 틀리면 null 대신 예외가 발생한다. 선택자, 실행 시점, 파일 경로를 나누어 확인한다.
  • 현재는 하나를 선택하는 querySelector에 집중한다.
    여러 항목을 한꺼번에 찾는 querySelectorAll은 요소 모음을 반환하므로 한 요소와 같은 값으로 취급하지 않는다.
