같은 작업을 조건에 맞춰 반복하기

횟수·종료 조건·배열의 값에 맞춰 반복문을 고른다.
반복을 시작하는 값과 끝내는 조건을 함께 읽는다.

이 페이지의 EXAMPLE은 05_loops.js의 연속된 구간이다.
브라우저 Console 또는 파일이 있는 폴더의 node 05_loops.js 명령으로 전체 실행 결과를 확인할 수 있다.

REPEAT

반복은 같은 코드를 다시 실행하는 규칙이다

같은 계산을 여러 번 작성하는 대신 반복문으로 실행 조건과 처리 범위를 정할 수 있다.
반복문에는 언제 시작하고, 무엇을 반복하며, 어떤 조건에서 멈추는지가 함께 들어가야 한다.

  • for는 반복 제어를 한곳에 모은다. 초기값·조건식·증감식을 괄호 안에 나누어 적는다.
    정해진 범위의 숫자나 배열 인덱스를 차례로 다룰 때 흐름을 읽기 쉽다.
  • while은 조건이 참인 동안 반복한다. 반복 전에 조건을 검사하고, 거짓이면 본문에 들어가지 않는다.
    반복 횟수보다 현재 상태가 종료 조건에 도달했는지가 중요할 때 사용한다.
  • for...of는 배열의 값을 꺼낸다. 인덱스 계산 없이 배열에 들어 있는 값을 순서대로 받는다.
    몇 번째인지가 필요하지 않고 항목 자체를 처리하면 될 때 간결하다.

EXAMPLE

for의 초기값·조건·본문·증감을 순서대로 읽기

for (초기값; 조건식; 증감식)에서 초기값은 처음 한 번만 실행한다.
이후에는 조건 확인 → 본문 → 증감 → 조건 확인 순서가 반복된다.

  • 초기값은 index = 1이다. 현재 반복 위치를 나타내는 변수를 준비한다.
    total은 반복문 밖에서 0으로 준비하여 여러 회차의 합계를 유지한다.
  • 조건은 index <= 3이다. 1·2·3은 본문을 실행하고, index가 4가 되면 멈춘다.
    마지막 값 3까지 포함하려면 <가 아니라 <=를 사용한다.
  • 본문 다음에 index += 1이 실행된다. 본문이 1을 합계에 더한 뒤에 index가 2로 바뀐다.
    index를 증가시키지 않으면 같은 조건을 계속 만족할 수 있다.
조건 검사 시 indexindex <= 3본문 처리 후 total다음 index
1true12
2true33
3true64
4false본문을 실행하지 않음반복 종료
05_loops.jsEXAMPLE
let total = 0;
// ***** TODO 1. 1부터 3까지 반복하면서 현재 값과 누적 합계 출력하기 *****
for (let index = 1; index <= 3; index += 1) {
  total += index;
  console.log("현재 값:", index, "누적 합:", total);
}
// **************************************************************
console.log("최종 합계:", total);

완성 코드의 실행 결과

현재 값: 1 누적 합: 1
현재 값: 2 누적 합: 3
현재 값: 3 누적 합: 6
최종 합계: 6

세 번 실행되는 동안 total은 0 → 1 → 3 → 6으로 바뀐다.
반복이 끝난 다음 문장은 한 번 실행되므로 최종 합계 6이 한 줄 더 출력된다.

EXAMPLE

while은 본문이 종료 조건을 향해 상태를 바꾼다

remaining이 양수인 동안 남은 횟수를 출력하고 1씩 줄인다.
조건에 쓰는 변수가 반복 중에 어떻게 바뀌는지 함께 확인한다.

  • 처음부터 조건이 거짓이면 0회 실행한다. remaining이 0으로 시작하면 while 본문을 한 번도 실행하지 않는다.
    반복 뒤 문장은 그대로 실행되므로 결과를 확인할 수 있다.
  • 이 예제는 출력한 뒤 감소시킨다. 3을 출력한 뒤 2가 되고, 1을 출력한 뒤 0이 된다.
    다음 조건 검사에서 0 > 0이 false이므로 종료한다.
  • 감소문이 빠지면 종료하지 못할 수 있다. remaining이 계속 3이면 조건도 계속 true이다.
    종료 조건과 상태 변경을 한 묶음으로 확인하며, 실제 무한 반복 코드는 실행하지 않는다.
05_loops.jsEXAMPLE
let remaining = 3;
// ***** TODO 2. remaining이 양수인 동안 출력하고 1씩 줄이는 while 작성하기 *****
while (remaining > 0) {
  console.log("남은 횟수:", remaining);
  remaining -= 1;
}
// **************************************************************
console.log("반복 종료 후:", remaining);

완성 코드의 실행 결과

남은 횟수: 3
남은 횟수: 2
남은 횟수: 1
반복 종료 후: 0

출력은 3·2·1이고 반복이 끝난 시점의 remaining은 0이다.
출력되는 값과 반복 종료 후의 값이 같지 않다는 점이 while의 검사 시점을 보여 준다.

EXAMPLE

for...of로 배열의 가격을 하나씩 더하기

배열의 모든 가격을 합산할 때는 현재 인덱스보다 가격 값이 필요하다.
for...of는 prices에서 값을 하나씩 꺼내 price라는 이름으로 사용하게 한다.

  • price는 인덱스가 아니라 값이다. 첫 회차에는 1200, 두 번째에는 1800, 세 번째에는 2000이다.
    0·1·2 같은 위치가 필요한 경우에는 인덱스를 사용하는 for를 고른다.
  • const price는 각 회차의 항목이다. 회차마다 현재 값이 그 이름에 연결되며 본문에서 다시 대입하지 않는다.
    합계처럼 반복 사이에 바뀌는 값은 바깥의 let 변수 priceTotal에 저장한다.
  • 원본 배열을 바꾸는 코드는 없다. prices에서 값을 읽어 합계에 더할 뿐이다.
    빈 배열이라면 본문을 실행하지 않아 합계는 처음 값 0으로 남는다.
05_loops.jsEXAMPLE
const prices = [1200, 1800, 2000];
let priceTotal = 0;
// ***** TODO 3. for...of로 prices의 값을 하나씩 받아 합계에 더하기 *****
for (const price of prices) {
  priceTotal += price;
}
// **************************************************************
console.log("가격 합계:", priceTotal);

완성 코드의 실행 결과

가격 합계: 5000

1200 + 1800 + 2000이 5000으로 합산된다.
배열의 값마다 한 번씩 같은 처리를 적용했으며 prices 자체는 그대로이다.

EXAMPLE

break는 반복을 끝내고 continue는 이번 회차만 넘긴다

두 반복문 모두 1부터 5까지의 값을 읽지만 3을 만났을 때의 동작이 다르다.
break와 continue 아래에 있는 출력문이 실행되는지 비교한다.

  • break는 현재 반복문에서 나온다. 3을 만나는 순간 반복이 끝나므로 3·4·5는 출력하지 않는다.
    가장 가까운 반복문 하나를 종료하는 것이지 프로그램 전체를 끝내는 것은 아니다.
  • continue는 현재 회차의 남은 문장만 건너뛴다. 3은 출력하지 않지만 다음 값 4와 5의 처리는 계속한다.
    for에서는 증감식으로, while에서는 다음 조건 검사로 진행한다.
  • while에서 continue 위치를 조심한다. 필요한 감소·증가 문장보다 먼저 continue를 만나면 상태가 바뀌지 않을 수 있다.
    이번 비교는 유한한 배열을 읽는 for...of이므로 항상 종료된다.
05_loops.jsEXAMPLE
const numbers = [1, 2, 3, 4, 5];
for (const number of numbers) {
  if (number === 3) {
    // ***** TODO 4. 3을 만나면 현재 반복문 전체를 끝내기 *****
    break;
    // **************************************************************
  }
  console.log("break 예제:", number);
}

for (const number of numbers) {
  if (number === 3) {
    continue;
  }
  console.log("continue 예제:", number);
}
console.log("두 반복문 뒤 문장");

완성 코드의 실행 결과

break 예제: 1
break 예제: 2
continue 예제: 1
continue 예제: 2
continue 예제: 4
continue 예제: 5
두 반복문 뒤 문장

break 예제는 1·2만, continue 예제는 1·2·4·5를 출력한다.
두 반복문을 모두 마친 뒤 마지막 안내 문장은 한 번 실행된다.
