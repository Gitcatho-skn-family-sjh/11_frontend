JAVASCRIPT 03

연산 결과를 조건으로 바꾸고 실행 경로를 고른다

산술 연산으로 값을 계산하고, 비교와 논리식으로 판단을 만든다.
참처럼 취급되는 값과 실제 조건을 구분하여 if·else if·else의 경계를 정확히 작성한다.

산술 · 증감truthy · falsyif · 삼항 연산자

JAVASCRIPT

산술 연산과 값의 갱신을 구분한다

연산자는 값에 수행할 처리를 지정하는 기호이다.
계산식을 평가하는 것과 계산 결과를 변수에 다시 저장하는 것은 다른 작업이다.

  • +·-·*·/는 합·차·곱·나눗셈에 사용하며, %는 나머지를 구한다.
    17 % 5는 17을 5로 나눈 나머지 2이다.
  • count + 1만 계산하면 count 자체는 바뀌지 않는다.
    count = count + 1 또는 count += 1로 결과를 저장해야 현재 값이 갱신된다.
  • count++는 1 증가, count--는 1 감소시킨다.
    증감 표현식을 다른 계산에 섞으면 전위·후위에 따라 사용되는 값이 달라지므로, 처음에는 한 줄의 독립 문장으로 사용한다.
  • 곱셈과 나눗셈은 덧셈과 뺄셈보다 먼저 계산된다.
    처리 순서가 중요하면 (2 + 3) * 4처럼 괄호로 묶는다.

EXAMPLE

나머지를 구하고 수량을 차례로 갱신한다

묶음으로 나눈 뒤 남는 개수를 %로 계산한다.
수량은 한 번 증가시키고, 세 개 추가한 뒤 하나 감소시킨다.

03_operators_conditions.jsEXAMPLE
const pieces = 17;
const boxSize = 5;
console.log("나눗셈:", pieces / boxSize);
console.log("나머지:", pieces % boxSize);
let count = 2;
count++;
console.log("하나 증가:", count);
// ***** TODO 1. 복합 대입 연산자로 count에 3 더하기 *****
count += 3;
// **************************************************************
console.log("세 개 추가:", count);
count--;
console.log("하나 감소:", count);
console.log("계산 순서:", 2 + 3 * 4, (2 + 3) * 4);

정상 실행 결과

나눗셈: 3.4
나머지: 2
하나 증가: 3
세 개 추가: 6
하나 감소: 5
계산 순서: 14 20

17 / 5는 3.4이고 나머지는 2이다.
수량은 2 → 3 → 6 → 5로 바뀐다. 마지막 비교는 괄호 유무에 따라 14와 20으로 달라진다.

JAVASCRIPT

비교 결과를 논리 연산자로 연결한다

비교 연산은 두 값의 관계를 불리언으로 만든다.
여러 조건이 모두 필요한지, 하나만 필요한지에 따라 논리 연산자를 선택한다.

  • >와 <는 크기를 비교하고 >=와 <=는 같은 값도 포함한다.
    30000 이상이면 30000을 포함하는 >=를 사용한다.
  • ===는 자료형까지 구분하여 같은지 비교하고, !==는 다른지 비교한다.
    =는 저장하는 대입이므로 조건에서 서로 혼동하지 않는다.
  • &&(AND)는 모두 만족, ||(OR)는 하나 이상 만족, !(NOT)는 불리언 판단을 뒤집는다.
    아래에서는 불리언 값과 비교 결과를 조합해 전체 조건을 만든다.

EXAMPLE

금액과 배송 가능 여부를 함께 판단한다

금액이 30000 이상이면서 배송 가능한 경우에만 무료 배송을 적용한다.
하나의 비교 결과와 배송 가능 여부를 AND로 연결한다.

03_operators_conditions.jsEXAMPLE
const amount = 30000;
const canDeliver = true;
const hasCoupon = false;
const isMember = true;
let canUseFreeShipping;
// ***** TODO 2. 금액 기준과 배송 가능 여부를 모두 만족하는 조건 대입하기 *****
canUseFreeShipping = amount >= 30000 && canDeliver;
// **************************************************************
console.log("무료 배송 적용:", canUseFreeShipping);
console.log("자료형까지 같은가:", "30000" === 30000);
console.log("서로 다른가:", "30000" !== 30000);
console.log("쿠폰 또는 멤버십:", hasCoupon || isMember);
console.log("배송 불가인가:", !canDeliver);

정상 실행 결과

무료 배송 적용: true
자료형까지 같은가: false
서로 다른가: true
쿠폰 또는 멤버십: true
배송 불가인가: false

금액 기준과 배송 가능 여부가 모두 참이므로 무료 배송 적용은 true이다.
문자열과 숫자는 자료형이 달라 ===는 false이며, !true는 false가 된다.

JAVASCRIPT

truthy와 falsy는 값이 조건에서 취급되는 방식이다

조건문은 불리언 이외의 값도 참 또는 거짓처럼 판단한다.
참처럼 취급되면 truthy, 거짓처럼 취급되면 falsy라고 한다. 값의 자료형이 실제로 불리언으로 바뀌는 것은 아니다.

  • 대표적인 falsy: false, 0, -0, 0n, 빈 문자열 "", null, undefined, NaN이다.
    수량 0이 허용되는 경우에도 0은 falsy이므로, 필요한 입력 규칙을 명시적으로 비교해야 한다.
  • 주의할 truthy: "0", "false", 공백만 있는 문자열 " ", 빈 배열 [], 빈 객체 {}도 truthy이다.
    글자의 뜻이나 배열·객체가 비어 있는지를 자동으로 판단하는 규칙은 아니다.
  • 항목 수 검사: 배열에 항목이 있는지는 배열 자체가 아니라 items.length > 0으로 확인한다.
    길이와 속성 접근은 다음 배열 단원에서 자세히 다룬다.
  • 단축 평가: &&는 왼쪽이 falsy이면, ||는 왼쪽이 truthy이면 오른쪽을 평가하지 않는다.
    반환값도 항상 불리언이 아니라 선택된 피연산자의 원래 값이다.

EXAMPLE

빈 배열은 참처럼 취급되어도 항목은 없다

Boolean 변환으로 조건에서의 판단을 직접 확인한다.
빈 배열의 truthy 여부와 실제 항목 수 검사는 다른 질문이다.

03_operators_conditions.jsEXAMPLE
const items = [];
let hasItems;
// ***** TODO 3. items의 길이가 0보다 큰지 비교해 hasItems에 대입하기 *****
hasItems = items.length > 0;
// **************************************************************
console.log("0·빈 문자열·null:", Boolean(0), Boolean(""), Boolean(null));
console.log("문자열 0·false·공백:", Boolean("0"), Boolean("false"), Boolean(" "));
console.log("빈 배열·빈 객체:", Boolean(items), Boolean({}));
console.log("실제로 항목이 있는가:", hasItems);
console.log("빈 문자열 OR 기본값:", "" || "기본 이름");
console.log("이름 AND 표시값:", "민지" && "이름 있음");

정상 실행 결과

0·빈 문자열·null: false false false
문자열 0·false·공백: true true true
빈 배열·빈 객체: true true
실제로 항목이 있는가: false
빈 문자열 OR 기본값: 기본 이름
이름 AND 표시값: 이름 있음

빈 배열과 빈 객체는 true로 변환되지만 items.length는 0이므로 hasItems는 false이다.
OR와 AND 예제는 true·false가 아니라 선택된 문자열을 반환한다.

JAVASCRIPT

if·else if·else는 처음 맞는 실행 경로를 선택한다

if는 조건이 참인 경우를, else는 앞 조건이 맞지 않은 나머지 경우를 처리한다.
else if를 추가하면 여러 조건을 위에서부터 차례로 검사한다.

  • 같은 if 묶음에서는 처음 참인 경로를 실행한 뒤 나머지 경로를 건너뛴다.
    범위가 겹치는 조건은 검사 순서에 따라 결과가 달라질 수 있다.
  • 실행할 문장은 중괄호로 묶는다. 들여쓰기만으로 블록 범위가 결정되지는 않는다.
    블록 밖에서도 사용할 변수는 바깥에서 선언하고 안에서 값을 대입한다.
  • 좌석 0은 마감, 1~2는 마감 임박, 3 이상은 예약 가능으로 구분한다.
    경계인 0·2·3을 확인하면 같은 값을 포함하는지와 빠진 범위를 점검할 수 있다.

EXAMPLE

좌석 수의 경계에 맞는 안내를 만든다

남은 좌석 수를 입력으로 받아 안내 문자열 하나를 선택한다.
이 예제는 좌석 수가 0 이상의 정수라는 전제이며, 입력값 자체의 검증은 별도이다.

  • 2는 첫 조건 === 0을 통과하지 않지만 다음 조건 <= 2를 만족한다.
    따라서 마지막 else가 아니라 마감 임박 경로를 실행한다.
  • notice는 바깥에서 선언되어 출력문에서도 읽을 수 있다.
    블록 안에서 const notice를 새로 선언하면 바깥 notice를 갱신하는 것이 아니다.
03_operators_conditions.jsEXAMPLE
const remainingSeats = 2;
let notice = "";
// ***** TODO 4. 0자리·2자리 이하·그 밖을 if / else if / else로 구분하기 *****
if (remainingSeats === 0) {
  notice = "마감";
} else if (remainingSeats <= 2) {
  notice = "마감 임박";
} else {
  notice = "예약 가능";
}
// **************************************************************
console.log("남은 좌석:", remainingSeats);
console.log("좌석 안내:", notice);

정상 실행 결과

남은 좌석: 2
좌석 안내: 마감 임박

남은 좌석 2는 마감 임박으로 표시된다.
같은 코드에서 입력이 0이면 마감, 3이면 예약 가능 경로를 선택한다.

EXAMPLE

짧은 값 선택은 삼항 연산자로 표현할 수 있다

삼항 연산자는 조건 ? 참일 때 값 : 거짓일 때 값 형태로 값 하나를 선택한다.
여러 작업을 실행하는 분기보다 짧은 표시 문구를 고르는 경우에 적합하다.

  • 아래 if·else와 삼항 연산자는 같은 무료 배송 조건으로 같은 문장을 선택한다.
    조건의 결과를 문자열 하나로 바꾸고, 그 문자열을 출력에 사용한다.
  • 분기가 길거나 조건이 여러 단계이면 if·else를 사용한다.
    삼항 연산자를 여러 번 겹쳐 한 줄로 줄이면 판단 순서를 읽기 어려워질 수 있다.
03_operators_conditions.jsEXAMPLE
let labelWithIf = "";
if (canUseFreeShipping) {
  labelWithIf = "무료 배송";
} else {
  labelWithIf = "배송 조건 확인";
}
let labelWithConditional = "";
// ***** TODO 5. 삼항 연산자로 무료 배송 여부에 맞는 문자열 선택하기 *****
labelWithConditional = canUseFreeShipping ? "무료 배송" : "배송 조건 확인";
// **************************************************************
console.log("if로 선택한 값:", labelWithIf);
console.log("삼항으로 선택한 값:", labelWithConditional);

정상 실행 결과

if로 선택한 값: 무료 배송
삼항으로 선택한 값: 무료 배송

두 표현 모두 true인 무료 배송 조건에 따라 같은 문자열을 선택한다.
삼항은 if를 무조건 대신하는 문법이 아니라 짧은 값 선택을 표현하는 방법이다.
