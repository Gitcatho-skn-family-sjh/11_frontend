HTML 01

문서 정보와 화면 내용을 나누기

HTML 문서는 브라우저에게 문서의 정보와 사람이 읽을 화면을 서로 다른 자리로 전달한다.

HEAD

탭에서 확인하는 문서 정보

head는 페이지 본문보다 먼저 브라우저가 읽는 정보 영역이다.
문자 인코딩은 한글을 올바르게 읽게 하고, viewport는 작은 화면의 너비를 설정하며, title은 탭의 이름을 정한다.

이 정보는 본문에 큰 글자로 보이지 않아도 필요하다.
문서를 열었을 때 한글이 깨지거나 탭 이름이 애매하면 내용을 읽기 전부터 사용자가 길을 잃는다.

  • head: 탭 제목, 문자 인코딩, 화면 너비처럼 브라우저가 문서를 해석하는 데 필요한 정보를 둔다.
    대부분 본문에 직접 보이지 않지만 문서가 올바르게 열리기 위한 설정이다.
  • charset: UTF-8을 지정하면 브라우저가 한글을 어떤 문자 체계로 읽어야 하는지 알 수 있다.
    이 값이 빠지거나 잘못되면 글자가 깨져 보일 수 있다.
  • viewport: 모바일 브라우저가 실제 기기 폭을 기준으로 화면을 계산하게 한다.
    이 설정은 뒤의 반응형 CSS가 390px 같은 작은 폭에서 의도대로 동작하는 출발점이다.
  • title: 페이지 본문이 아니라 브라우저 탭과 방문 기록에 표시되는 문서 이름이다.
    여러 탭을 열었을 때 내용을 구분할 수 있도록 구체적으로 작성한다.

BODY

사람이 읽는 본문은 body에 둔다

body에는 제목, 문단, 목록처럼 화면에 보이는 요소를 작성한다.
HTML은 위에서 아래로 읽히므로 제목 뒤에 설명을 두면 브라우저도 그 순서로 화면을 만든다.

이후 CSS는 body 안 요소의 모양을 바꾸고 JavaScript는 body 안 요소를 찾는다.
그래서 문서 골격을 정확히 나누는 일은 모든 다음 실습의 시작점이다.

  • body: 제목, 문단, 목록, 양식처럼 사용자가 화면에서 읽고 조작할 내용을 둔다.
    CSS와 JavaScript가 다룰 실제 요소들도 이 영역에 작성한다.
  • h1: 페이지 전체에서 가장 중요한 주제를 나타내는 제목이다.
    단순히 글자를 크게 만드는 태그가 아니라 문서의 중심 내용을 알려 주는 역할을 한다.
  • p: 제목을 뒷받침하는 설명을 하나의 문단으로 묶는다.
    서로 다른 주제를 한 문단에 길게 넣기보다 의미가 바뀌는 지점에서 새 문단으로 나눈다.
  • 작성 순서: HTML에 적은 위아래 순서는 화면과 보조 기술의 기본 읽기 순서가 된다.
    모양만 보고 순서를 정하지 말고 중요한 정보가 자연스럽게 이어지도록 구조를 작성한다.

EXAMPLE

제목, 문단 작성하기

<head>
  <title>나의 첫 페이지</title>
</head>

<body>
  <h1>안녕하세요</h1>
  <h2>안녕하세요</h2>
  <h3>안녕하세요</h3>
  <h4>안녕하세요</h4>
  <h5>안녕하세요</h5>
  <h6>안녕하세요</h6>

  <p>처음 만든 웹 문서입니다.</p>
</body>
