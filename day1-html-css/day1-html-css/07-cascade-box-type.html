CSS · BOX MODEL

내용과 여백을 구분하면 박스 크기를 설명할 수 있다

화면의 요소는 내용만큼의 공간만 차지하지 않는다.
content, padding, border, margin을 구분하고 같은 너비 선언이 어떤 크기를 만드는지 비교한다.

contentpadding · border · marginbox-sizingline-height

BOX MODEL

하나의 요소를 안에서 밖으로 읽는 네 가지 기준

박스 모델은 요소의 내용과 그 주변 공간을 계산하는 방식이다.
카드가 너무 넓거나 버튼 사이가 좁을 때 어느 영역을 바꿔야 하는지 알려 준다.

  • content — 실제 내용 영역: 글자, 이미지, 자식 요소가 놓인다.
    content라는 너비 속성을 쓰는 것이 아니라 width, height와 내용의 크기로 영역이 결정된다. content: 속성은 가상 요소 등에서 쓰는 별개의 속성이다.
  • padding — 테두리 안쪽 여백: 글자와 테두리 사이를 벌린다.
    요소의 배경이 칠해지고 버튼이라면 클릭 가능한 박스 안에 포함된다. 내용이 테두리에 붙어 답답할 때 사용한다.
  • border — 요소를 감싸는 경계: 선의 두께도 박스 크기에 포함된다.
    border: 2px solid black은 두께, 선 종류, 색을 한 번에 지정한다.
  • margin — 테두리 바깥 여백: 이웃 요소와 거리를 만든다.
    요소 자신의 배경색은 칠해지지 않는다. 화면에서 margin 색처럼 보이는 부분은 뒤에 놓인 부모의 배경이다.

아래 색상은 영역을 구분하기 위한 표시이다.
브라우저 개발자 도구에서 요소를 선택한 뒤 박스 모델 도식을 열면 같은 네 영역의 실제 계산값도 확인할 수 있다.

EXAMPLE

1. 배경색과 경계선으로 네 영역 구분하기

파란 내용 영역을 노란 padding, 갈색 border, 분홍색 바깥 공간이 둘러싼다.
내용의 너비는 220px이고, 여백과 테두리를 더한 박스 너비는 276px이다.

  • 테두리까지의 너비: 220 + 20 × 2 + 8 × 2 = 276px이다. 여기서 276px은 좌우 테두리 바깥쪽 사이의 거리이다.
  • 좌우 margin 포함: 276 + 32 × 2 = 340px이다. 분홍 무대의 너비와 정확히 같다.
  • 색의 의미: 노란 배경은 카드에, 파란 배경은 안쪽 자식 요소에 지정했다. margin 자체에 배경색을 지정한 것이 아니다.
.bm-model-card {
  box-sizing: content-box;
  width: 220px;
  padding: 20px;
  border: 8px solid #a35b16;
  margin: 24px 32px;
  background: #ffdc66;
}

/* 안쪽 자식 요소가 content 영역을 보여 준다. */
.bm-content { background: #bdefff; }
content 220px
글자와 이미지가 놓이는 곳
높이 72px
파랑: content노랑: padding 20px갈색: border 8px분홍: margin

padding: 20px을 10px로 바꾸면 내용 너비는 그대로이고 테두리 바깥 너비는 256px로 줄어든다.
이 예제는 content-box이므로 padding을 바꿔도 content의 220px은 유지된다.

EXAMPLE

2. padding을 늘린 카드와 margin을 늘린 카드 비교하기

두 카드의 content 너비는 모두 180px이고 테두리는 2px이다.
같은 24px을 어디에 넣는지에 따라 노란 카드 자체의 크기가 달라진다.

.bm-space-card {
  box-sizing: content-box;
  width: 180px;
  border: 2px solid #142023;
  background: #ffdc66;
}
.bm-space-padding { padding: 24px; margin: 0; }
.bm-space-margin  { padding: 0; margin: 24px; }

padding 24px — 안쪽을 넓힌다

내용 너비 180px

margin 24px — 바깥을 벌린다

내용 너비 180px
  • padding 카드: 테두리 바깥 너비는 180 + 48 + 4 = 232px이다. 글자와 테두리 사이에 노란 공간이 생긴다.
  • margin 카드: 테두리 바깥 너비는 180 + 4 = 184px이다. 양옆 margin까지 포함하면 232px이지만 노란 박스 자체는 작다.
  • 바꿔 볼 값: 두 예제의 24px을 각각 8px로 낮춘다. 첫 카드는 내부가 좁아지고, 둘째 카드는 부모 가장자리와 가까워진다.

EXAMPLE

3. 네 방향의 여백과 선을 축약해서 작성하기

네 방향을 항상 같은 값으로 만들 필요는 없다.
값을 네 개 쓰면 위에서 시작해 오른쪽, 아래, 왼쪽으로 시계 방향으로 적용된다.

  • 값 1개: padding: 12px — 네 방향 모두 12px이다.
  • 값 2개: padding: 12px 20px — 위·아래 12px, 왼쪽·오른쪽 20px이다.
  • 값 3개: padding: 12px 20px 28px — 위 12px, 왼쪽·오른쪽 20px, 아래 28px이다.
  • 값 4개: padding: 10px 20px 30px 40px — 위 10px, 오른쪽 20px, 아래 30px, 왼쪽 40px이다.
  • 한 방향만: padding-left: 40px, margin-bottom: 16px, border-top: 4px solid blue처럼 쓴다. padding과 margin은 같은 방향 순서를 사용한다.
.bm-short-card {
  box-sizing: content-box;
  width: 220px;
  padding: 10px 20px 30px 40px; /* 위 → 오른쪽 → 아래 → 왼쪽 */
  border: 4px dashed #0057d9;   /* 두께 → 선 종류 → 색 */
  margin: 12px 16px;           /* 위아래 → 좌우 */
  background: #ffdc66;
}
위 10px · 오른쪽 20px
아래 30px · 왼쪽 40px

왼쪽 노란 공간은 오른쪽의 두 배이고, 아래쪽은 위쪽의 세 배이다.
dashed를 solid로 바꾸면 선 종류만 바뀌고 4px 두께는 그대로이다.

border는 solid, dashed 같은 선 종류도 지정해야 보인다.
border-color만 바꿨는데 선이 보이지 않는다면 기본 border-style: none 상태인지 확인한다.

EXAMPLE

4. width 240px은 내용의 너비일까, 테두리까지의 너비일까?

box-sizing은 width와 height를 어느 경계까지 계산할지 정한다.
두 예제에 똑같이 width 240px, padding 20px, border 4px을 주고 계산 기준만 바꾼다.

  • content-box: width는 내용 너비이다. 전체 너비는 240 + 20 × 2 + 4 × 2 = 288px이 된다.
  • border-box: width 안에 padding과 border가 포함된다. 전체 너비는 240px이고, 내용 너비는 240 − 40 − 8 = 192px이다.
  • margin은 별도: 어떤 box-sizing을 사용하든 바깥 margin은 width 안에 포함하지 않는다.
  • 이 교안의 공통 설정: lesson.css는 모든 요소에 box-sizing: border-box를 적용한다. 첫 예제에는 content-box를 명시해서 기본 교안 설정을 바꾼다.
.bm-size-box {
  width: 240px;
  padding: 20px;
  border: 4px solid #142023;
}
.bm-size-content { box-sizing: content-box; } /* 전체 288px */
.bm-size-border  { box-sizing: border-box; }  /* 전체 240px */

content-box: 내용 240px + 여백과 선

기준선 240px
content 240px
전체 너비 288px

border-box: 전체 240px 안에 배분

기준선 240px
content 192px
전체 너비 240px

두 박스의 padding을 30px로 바꿔 본다.
content-box의 전체 너비는 308px로 늘지만, border-box의 전체 너비는 240px을 유지하고 내용 너비가 172px로 줄어든다.

고정 너비와 작은 화면

정확한 숫자를 비교하기 위해 이 예제들은 실험 박스의 너비를 고정했다.
좁은 화면에서는 예제 내부만 가로로 스크롤할 수 있다. 실제 페이지의 카드에는 보통 box-sizing: border-box와 max-width: 100%를 함께 사용해 padding과 border를 포함한 너비가 부모를 넘지 않도록 설계한다.

EXAMPLE

5. 남는 가로 공간을 margin: auto로 나누기

일반 블록 요소에 부모보다 작은 너비를 주고 좌우 margin을 auto로 지정하면 남는 공간을 양쪽에 나누어 배치한다.
글자를 가운데 정렬하는 text-align: center와는 달리 박스 자체의 위치를 바꾸는 방법이다.

.bm-center-stage { width: 320px; }
.bm-center-card {
  box-sizing: border-box;
  width: 200px;
  padding: 12px;
  border: 2px solid #142023;
  margin: 16px auto;
}
/* 남은 120px을 왼쪽 60px, 오른쪽 60px로 나눈다. */
박스 너비 200px
글자는 왼쪽 정렬
  • 너비 계산: 부모 320px에서 박스 200px을 뺀 120px이 남는다. 좌우 auto가 각각 60px을 사용한다.
  • 너비를 240px로 바꾸면: 좌우는 각각 40px이 된다. 부모 너비를 모두 채우는 블록에는 나눌 공간이 없으므로 이동이 눈에 보이지 않는다.
  • 세로 중앙은 다른 문제: 일반 블록 배치에서 위아래 auto margin만으로 세로 가운데 정렬되지 않는다. 다음 파일에서 Flex의 축과 정렬로 다룬다.

EXAMPLE

6. 위아래 margin은 언제나 더해지지 않는다

일반 블록 흐름에서 인접한 두 요소의 양수 세로 margin은 하나로 합쳐질 수 있다.
이를 margin collapse(마진 상쇄)라고 하며, 아래 예제에서는 24px와 40px 중 큰 40px이 두 박스 사이의 간격이 된다.

.bm-collapse-stage { display: flow-root; }
.bm-collapse-box { display: block; margin: 0; }
.bm-collapse-first  { margin-bottom: 24px; }
.bm-collapse-second { margin-top: 40px; }
/* 두 형제 박스 사이: 24 + 40이 아니라 40px */

/* 비교: Flex 자식에는 margin을 주지 않고 gap으로 간격을 지정한다. */
.bm-gap-stage {
  display: flex;
  flex-direction: column;
  gap: 24px;
}

일반 블록: 사이 간격 40px

아래 margin 24px
위 margin 40px

Flex + gap: 사이 간격 24px

자식 margin 0
자식 margin 0
  • 실제 경계를 잰다: 첫 박스의 아래 테두리부터 둘째 박스의 위 테두리까지가 40px이다. 글자 사이의 거리는 padding과 줄 높이가 섞이므로 같은 값이 아니다.
  • flow-root의 역할: 이 예제의 부모와 자식 사이로 margin이 빠져나가는 상황을 분리하기 위한 설정이다. 내부에서 일반 블록으로 놓인 두 형제의 세로 margin 상쇄는 여전히 일어난다.
  • 상쇄되지 않는 경우: 좌우 margin에는 이 규칙을 적용하지 않는다. Flex·Grid 아이템 사이의 margin도 상쇄되지 않는다. Flex에서는 간격을 gap으로 모아 관리하는 방법을 자주 사용한다.
  • 값을 바꾸면: 둘째 박스의 margin-top을 12px로 줄이면 사이 간격은 24px이 된다. 음수 margin과 부모·자식 간 상쇄는 이 예제의 계산 범위에서 제외한다.

EXAMPLE

7. 글자 크기와 줄 높이도 content의 높이를 바꾼다

카드 높이를 따로 지정하지 않으면 보통 내용의 높이에 따라 카드가 늘어난다.
font-size는 글자 크기이고, line-height는 한 줄이 차지하는 높이이다. 둘은 같은 값이 아니다.

  • 단위 없는 line-height: font-size: 16px; line-height: 1.25는 한 줄 높이를 16 × 1.25 = 20px로 만든다.
  • 높이를 비교하는 조건: 아래 문단은 margin이 0이고 <br>로 정확히 두 줄을 만든다. 세 카드의 padding 12px, border 2px은 동일하다.
  • 내용이 늘어난 경우: 실제 문장이 길거나 화면이 좁으면 자동 줄바꿈으로 줄 수가 늘어난다. 이런 카드에 작은 고정 height를 강요하면 내용이 넘칠 수 있다.
.bm-type-card {
  box-sizing: content-box;
  width: 240px;
  padding: 12px;
  border: 2px solid #142023;
}
.bm-type-card > p { margin: 0; font-size: 16px; }
.bm-type-compact > p { line-height: 1.25; } /* 16 × 1.25 = 20px */
.bm-type-roomy > p   { line-height: 2; }    /* 16 × 2 = 32px */
.bm-type-large > p   { font-size: 20px; line-height: 1.6; } /* 32px */

첫 카드 높이는 20 × 2 + 12 × 2 + 2 × 2 = 68px이다.
둘째와 셋째는 글자 크기가 달라도 한 줄 높이가 32px로 같아서 전체 높이도 모두 92px이다.

줄 높이를 크게 한다고 글자 자체가 커지지는 않는다.
읽기 편한 문단을 만들 때는 font-size로 글자 크기를, line-height로 줄 사이의 호흡을 따로 조절한다.
