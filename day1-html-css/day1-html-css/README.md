# Day 1 · HTML과 CSS

주제별 HTML 파일을 브라우저와 편집기에서 함께 연다. 브라우저에는 설명, 완성된 예제 코드, 실제 예제 화면이 차례로 표시된다. 편집기에서 해당 예제의 `TODO`를 채우고 저장한 뒤 브라우저를 새로고침한다.

설명과 예제 코드는 강사용 교안과 동일하다. 실제 HTML·CSS의 지정된 코드만 비어 있으며, 빈칸 밖의 구조·문장·색상·목차는 제공되어 있다.

파일은 주제 단위이며 교시 단위가 아니다. 한 파일의 여러 예제를 차례로 비교하며 진행하고, 다음 파일을 열기 위해 이전 파일을 완성할 필요는 없다.

## 예제 코드와 작성 위치

- **브라우저에 보이는 코드:** 결과를 만들기 위한 예제이다. 소스에서는 `<pre><code>` 안에 들어 있으며 이 부분은 수정하지 않는다.
- **HTML 빈칸:** `TODO` 주석 바로 뒤의 태그 속성이나 시작·끝 주석 사이에 작성한다. `<template>` 안의 HTML도 실제 예제 코드이며, 저장하고 새로고침하면 독립된 미리보기 문서에 반영된다.
- **CSS 빈칸:** 각 HTML의 `<head>` 안 `<style>`에 있다. 선택자와 중괄호가 제공되어 있으면 선언만 작성하고, 주석 사이 전체가 비어 있으면 선택자·중괄호를 포함한 규칙을 작성한다.
- **제공 파일:** `../assets/lesson.css`, `../assets/day1.css`, `../assets/day1-nav.js`는 설명 화면과 목차를 위한 파일이다. CSS 예제를 완성하려고 이 파일을 수정하지 않는다.

속성만 작성하는 위치는 태그가 남아 있다. 제공된 다른 속성은 그대로 두고 주석에 적힌 속성만 추가한다.

```html
<!-- ***** TODO 1. 문서의 주 언어를 나타내는 lang 값 작성하기 *****-->
<html>
```

요소 전체를 작성하는 위치는 시작 주석과 끝 경계선 사이가 비어 있다.

```html
<!-- ***** TODO 2. 브라우저 탭에서 문서를 구분하는 이름인 title 작성하기 *****-->

<!-- ************************************************************** -->
```

## 열기와 이동

1. 배포받은 `student-workbook` 폴더 구조를 유지한다. HTML만 따로 옮기면 스타일과 목차 경로가 끊어진다.
2. [01-html-document.html](01-html-document.html)을 브라우저로 연다.
3. 편집기에서 같은 파일을 열고 `TODO 1`부터 찾는다.
4. 화면의 해당 예제 코드를 참고해 실제 빈칸을 채운다.
5. 저장하고 브라우저를 새로고침한다. 코드 작성 전후의 화면을 비교한다.
6. 왼쪽 목차에서 다음 주제나 현재 페이지의 다른 예제로 이동한다. 1180px 미만 화면에서는 상단의 `DAY 1 · HTML & CSS`를 펼쳐 목차를 사용한다.

빈칸 상태에서 예제 요소가 없거나 기본 배치로 보이는 것은 정상이다. 첫 파일의 언어와 탭 이름도 각각 `lang`과 `title`을 채운 뒤 완성된다. 설명 화면까지 스타일 없이 보이거나 목차가 나오지 않으면 `assets` 폴더와 상대 경로를 먼저 확인한다.

Flex 줄바꿈 예제는 `flex-wrap`을 작성하기 전까지 항목이 한 줄에 놓인다. 페이지 전체가 밀리지 않도록 넘친 항목은 예제 상자 안에서 가로 스크롤로 확인할 수 있다. 줄바꿈 선언을 채우면 항목이 다음 줄로 이동한다.

정적 서버를 사용하는 경우에는 `student-workbook` 폴더에서 다음 명령을 실행한다. 별도 패키지 설치는 필요하지 않다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000/day1-html-css/01-html-document.html`을 연다.
