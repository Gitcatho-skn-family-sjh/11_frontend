CSS · FLEX LAYOUT

방향을 정하고, 두 축의 공간을 배분한다

Flex는 한 방향으로 놓인 항목의 크기와 간격을 조정하는 배치 방식이다.
먼저 부모와 주축을 찾고, 그다음 정렬할 축과 남은 공간을 확인한다.

1. 배치하려는 항목의 공통 부모를 찾는다

display: flex를 선언한 요소는 Flex container가 되고, 바로 아래 자식은 Flex item이 된다.
카드 안의 제목이나 문단까지 자동으로 같은 행에 놓이는 것은 아니다.

아래 코드에는 배치의 차이를 만드는 규칙을 중심으로 표시했다.
실제 소스의 선택자 앞에는 예제 스타일이 다른 페이지에 영향을 주지 않도록 .flex-lesson이라는 공통 범위가 추가되며, 색상·테두리 등 비교에 필요한 장식은 미리 정의되어 있다.

  • 부모에 쓰는 속성: 방향, 줄바꿈, 항목 사이 간격, 전체 정렬은 container에서 정한다.
    카드 세 개를 나란히 놓으려면 세 카드를 감싼 요소에 선언한다.
  • 자식에 쓰는 속성: 항목별 크기 배분이나 개별 정렬은 item에서 정한다.
    각 카드에 display: flex를 쓰면 카드 내부에 또 다른 Flex 관계가 생긴다.
.fl-parent {
  display: flex;
  gap: .5rem;
}

  <div>A <span>A 안의 내용</span></div>
  <div>B</div>
  <div>C</div>

A, B, C만 부모의 직계 자식이므로 세 항목이 한 행에 놓인다.
A 안의 작은 문장은 별도의 Flex item이 아니라 A의 내용으로 남는다.

EXAMPLE

2. 주축은 항상 가로가 아니다

주축(main axis)은 항목이 나열되는 방향이고, 교차축(cross axis)은 주축과 직각인 방향이다.
이 예제는 일반적인 한국어 웹 문서처럼 가로쓰기와 왼쪽→오른쪽 방향을 사용한다.

  • row: 주축은 왼쪽→오른쪽, 교차축은 위→아래이다.
    기본 방향이므로 별도로 쓰지 않아도 가로 행으로 시작한다.
  • column: 주축은 위→아래, 교차축은 왼쪽→오른쪽이다.
    정렬 속성 이름은 그대로이고, 속성이 작용하는 물리적 방향이 바뀐다.
  • 방향을 판단하는 순서: 먼저 flex-direction을 확인한다.
    “justify는 가로”로 외우면 column 배치를 설명할 수 없다.
.fl-axis {
  display: flex;
  gap: .5rem;
  min-height: 200px;
  align-items: flex-start;
}
.fl-row { flex-direction: row; }
.fl-column { flex-direction: column; }

두 상자에 같은 A, B, C가 들어 있지만 나열되는 방향만 다르다.
row-reverse와 column-reverse는 주축의 시작과 끝을 뒤집는다. 시각 순서와 HTML 읽기 순서가 달라질 수 있으므로 순서 수정 용도로 남용하지 않는다.

3. justify-content는 주축의 남는 공간을 배분한다

항목들의 크기를 정한 뒤 주축에 여유 공간이 있으면 그 공간을 어디에 둘지 결정한다.
아래는 너비가 일정한 세 항목을 같은 가로 행에 배치한 비교이다.

  • flex-start / center / flex-end: 항목 묶음을 주축의 시작·가운데·끝에 둔다.
    row에서는 왼쪽·가운데·오른쪽이고, column에서는 위·가운데·아래이다.
  • space-between: 첫 항목과 마지막 항목을 양 끝에 두고 남는 공간을 사이에 나눈다.
    항목이 하나뿐이면 시작에 놓이며, 고정 간격을 만드는 속성은 아니다.
  • 여유 공간이 없으면: 항목이 부모를 모두 채울 때 정렬값을 바꿔도 차이가 잘 보이지 않는다.
    특히 모든 항목이 flex: 1로 공간을 이미 차지했는지 확인한다.
.fl-justify { display: flex; gap: .25rem; }
.fl-justify .fl-tile { flex: 0 0 36px; }

.fl-start   { justify-content: flex-start; }
.fl-center  { justify-content: center; }
.fl-end     { justify-content: flex-end; }
.fl-between { justify-content: space-between; }

4. align-items는 교차축, align-self는 항목 하나의 정렬이다

row의 교차축은 세로이므로 부모 높이를 150px로 확보하면 위·중간·아래의 차이가 보인다.
부모가 내용만큼만 높다면 가운데 정렬을 해도 이동할 여유 공간이 거의 없다.

  • stretch: 교차축 크기가 자동인 항목을 줄의 높이만큼 늘린다.
    항목에 높이를 명시하면 그 높이까지 무시하며 늘리는 것은 아니다.
  • center / flex-start / flex-end: 항목을 늘리지 않고 교차축의 가운데·시작·끝에 둔다.
    column에서는 이 세 값이 가로 방향 정렬을 제어한다.
  • align-self: 부모의 align-items 대신 해당 item 하나에만 정렬을 적용한다.
    마지막 비교에서 B만 아래로 내려가고 A와 C는 위에 남는다.
.fl-align { display: flex; gap: .5rem; height: 150px; }
.fl-align .fl-tile { flex: 1; }
.fl-stretch      { align-items: stretch; }
.fl-align-center { align-items: center; }
.fl-align-start  { align-items: flex-start; }
.fl-align-end    { align-items: flex-end; }
.fl-self         { align-self: flex-end; } /* B에 적용 */

5. gap은 간격이고 space-between은 여유 공간 배분이다

gap: 16px은 이웃한 항목 사이에 16px의 간격을 둔다.
부모 바깥 여백이나 첫 항목 앞의 여백을 만들지는 않는다.

여기에 justify-content: space-between을 추가하면 고정 간격 외의 여유 공간도 항목 사이로 분배된다.
따라서 화면에서 측정한 실제 항목 간 거리는 16px보다 커질 수 있다.

.fl-gap { display: flex; gap: 16px; }
.fl-gap .fl-tile { flex: 0 0 36px; }
.fl-gap-distributed { justify-content: space-between; }

로고와 메뉴를 양 끝에 놓으려면 space-between처럼 여유 공간을 나누는 규칙이 적합하다.

6. flex-wrap으로 줄을 만들고 align-content로 줄 묶음을 정렬한다

기본값 nowrap은 공간이 부족해도 새 줄을 만들지 않는다.
flex-wrap: wrap을 지정하면 들어갈 수 없는 항목을 다음 줄로 보낸다.

  • 줄바꿈 조건: 아래 항목은 flex: 0 0 100px로 늘거나 줄지 않는 기준 폭을 갖는다.
    부모 안에 세 개가 들어가지 못하므로 두 줄로 나뉜다.
  • align-items: 각 줄 안에서 개별 항목의 교차축 정렬을 정한다.
    align-content: 여러 줄로 이루어진 묶음의 교차축 공간을 배분한다.
  • 차이가 보이는 조건: 여러 줄이 생기고, 교차축에 남는 공간이 있어야 한다.
    아래는 부모 높이를 230px로 정해 줄 사이 공간을 비교한다. nowrap 단일 줄에는 align-content가 적용되지 않는다.
.fl-wrap {
  display: flex;
  flex-wrap: wrap;
  width: min(100%, 280px);
  height: 230px;
  gap: 8px;
  align-items: flex-start;
}
.fl-wrap .fl-tile { flex: 0 0 100px; }
.fl-lines-start   { align-content: flex-start; }
.fl-lines-between { align-content: space-between; }

7. flex는 항목이 공간을 늘리고 줄이는 규칙이다

flex는 부모가 아니라 항목에 작성한다.
세 값을 순서대로 쓰면 flex-grow flex-shrink flex-basis이며, 남는 공간·부족한 공간·시작 크기를 각각 다룬다.

  • flex-grow: 주축의 여유 공간을 차지할 비율이다.
    0이면 여유 공간이 있어도 그 이유만으로 늘지 않는다.
  • flex-shrink: 공간이 부족할 때 줄어들 수 있는 비율이다.
    실제 축소량은 기준 크기에도 영향을 받으므로 “1이면 모두 같은 픽셀만큼 감소”는 아니다.
  • flex-basis: 공간을 배분하기 전에 출발점으로 삼는 주축 크기이다.
    flex: 0 0 100px은 늘지도 줄지도 않는 100px 기준 항목이다.
  • flex: 1: 브라우저에서는 보통 1 1 0%로 확장된다.
    같은 기준에서 공간을 나누는 카드 배치에 편리하지만 padding·border·최소 크기가 다르면 전체 폭이 정확히 같지 않을 수 있다.
  • min-width: 0: 긴 내용 때문에 item이 내용의 최소 폭 아래로 줄지 못하는 제약을 풀어 준다.
    긴 단어를 줄바꿈하려면 내용에도 overflow-wrap: anywhere 같은 별도 처리 규칙이 필요하다.
.fl-share { display: flex; gap: .5rem; }
.fl-share .fl-tile {
  flex: 1;
  min-width: 0;
  overflow-wrap: anywhere;
}
.fl-share-ratio .fl-tile:first-child { flex: 2; }
