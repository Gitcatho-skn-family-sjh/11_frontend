CSS 05

원하는 요소를 정확히 고르는 선택자

같은 태그여도 위치·속성·상태에 따라 다른 모양이 필요하다.
CSS를 연결한 뒤, 규칙을 적용할 대상을 한 단계씩 좁혀 간다.

CSS 연결

HTML이 구조를 만들면 CSS가 모양을 지정한다

  • 외부 스타일시트: head 안의 link로 CSS 파일을 불러온다.
    rel="stylesheet"는 파일의 역할, href는 HTML 파일을 기준으로 한 경로이다. 여러 페이지에서 같은 CSS를 공유할 수 있다.
  • 내부 스타일시트: style 안에 규칙을 작성하면 해당 HTML에서 사용한다.
    이 페이지의 작은 예제는 결과를 바로 비교하도록 내부 스타일시트에 작성되어 있다.
  • 인라인 스타일: <p style="color: blue">처럼 한 요소에 선언을 직접 적는다.
    여러 요소의 디자인을 일관되게 고치기 어렵기 때문에 반복되는 모양은 class와 스타일시트로 관리한다.
  • 규칙의 구조: 선택자 { 속성: 값; }에서 선택자는 대상, 선언은 변경할 모양이다.
    한 규칙 안에 여러 선언을 쓰며, 선언 사이를 세미콜론으로 구분한다.
<!-- index.html의 head 안 -->
<link rel="stylesheet" href="styles.css">

/* styles.css */
.card {
  color: #0057d9;
  padding: 16px;
}

styles.css가 같은 폴더에 있다면 위 경로를 사용한다.
파일이 연결되지 않으면 선택자보다 먼저 파일 이름·폴더 위치·개발자 도구의 네트워크 오류를 확인한다.

EXAMPLE 1

태그는 종류, class는 묶음, id는 고유 대상을 고른다

  • p: 같은 종류의 모든 문단을 선택한다. 아래 예제에서는 세 문단의 글자가 모두 파란색이다.
  • .recommended: class 속성에 해당 이름이 있는 요소를 고른다. 반복되는 추천 카드 두 개가 배경을 공유한다.
  • #first-book: 해당 id의 요소를 고른다. id는 한 문서 안에서 중복하지 않는다.
  • 범위 제한: 앞의 .selector-basic은 예제 영역의 이름이다.
    이 영역 안만 꾸미므로 수업 설명의 모든 p까지 바뀌지 않는다. 공백으로 범위를 좁히는 방법은 다음 예제에서 확인한다.
.selector-basic p { color: #0057d9; }
.selector-basic .recommended { background: #e4efff; }
.selector-basic #first-book { border-left: 8px solid #9b3f00; }

<div class="selector-basic">
  <p id="first-book" class="recommended">웹 문서의 구조</p>
  <p>처음 만나는 디자인</p>
  <p class="recommended">작은 화면을 위한 배치</p>
</div>

웹 문서의 구조

처음 만나는 디자인

작은 화면을 위한 배치

첫 문단은 세 규칙의 대상이 된다.
서로 다른 속성이므로 파란 글자·연한 배경·두꺼운 왼쪽 선이 함께 적용된다.

EXAMPLE 2

공백은 모든 후손, >는 바로 아래 자식만 고른다

  • .catalog p: .catalog 안에 들어 있는 모든 p를 선택한다.
    중간에 다른 요소가 여러 겹 있어도 후손 관계이면 선택된다.
  • .catalog > p: 부모가 바로 .catalog인 p만 선택한다.
    중첩된 .nested 안의 문단은 손자이므로 제외된다.
  • 두 선택자의 차이: 아래 두 문단은 모두 파란 배경이지만 왼쪽 주황색 선은 첫 문단에만 생긴다.
    작은 카드 안에 또 다른 카드가 있을 때 직접 자식만 꾸미면 안쪽 카드까지 영향을 주는 일을 줄일 수 있다.
.selector-relations .catalog p { background: #e4efff; }
.selector-relations .catalog > p { border-left: 8px solid #9b3f00; }

<div class="catalog">
  <p>바로 아래 문단: 자식이자 후손</p>
  <div class="nested">
    <p>안쪽 문단: 후손이지만 직접 자식은 아님</p>
  </div>
</div>

바로 아래 문단: 자식이자 후손

안쪽 문단: 후손이지만 직접 자식은 아님

두 번째 규칙의 >를 공백으로 바꾸면 안쪽 문단에도 주황색 선이 생긴다.
값을 바꾸지 않아도 선택자만으로 적용 대상이 달라진다.

EXAMPLE 3

+와 ~는 같은 부모 아래의 뒤쪽 형제를 고른다

  • h3 + p: 같은 부모 안에서 h3 바로 다음에 오는 요소가 p이면 선택한다.
    태그 사이의 공백·줄바꿈은 요소가 아니므로 인접 관계를 끊지 않는다.
  • h3 ~ p: 같은 부모 안에서 h3 뒤에 나오는 모든 p를 선택한다.
    사이에 다른 요소가 있어도 되지만 이전 형제나 안쪽 후손은 선택하지 않는다.
.selector-siblings h3 + p { background: #ffdc66; }
.selector-siblings h3 ~ p { border-left: 8px solid #11643a; }

<p>제목 앞 문단</p>
<h3>도서 소개</h3>
<p>제목 바로 다음 문단</p>
<small>중간에 다른 요소가 있음</small>
<p>제목 뒤의 또 다른 문단</p>

제목 앞 문단

도서 소개

제목 바로 다음 문단

중간에 다른 요소가 있음

제목 뒤의 또 다른 문단

노란 배경은 한 문단, 초록색 왼쪽 선은 두 문단에 적용된다.
제목 앞 문단은 두 형제 선택자의 대상이 아니다.

EXAMPLE 4

속성 선택자는 HTML에 이미 있는 정보를 조건으로 쓴다

  • [data-featured]: 값과 관계없이 그 속성이 존재하는 요소를 고른다.
  • [type="email"]: 속성값이 정확히 일치하는 이메일 입력창을 고른다.
  • [href^="https://"]: 값이 해당 문자열로 시작하는 링크를 고른다.
  • [href$=".pdf"]: 값이 해당 문자열로 끝나는 링크를 고른다.
    manual.pdf?download=1은 끝부분이 다르므로 이 조건에 맞지 않는다.
  • [href*="guide"]: 값의 어느 위치든 해당 문자열을 포함하면 고른다.
    파일 종류를 실제로 검사하는 것이 아니라 HTML 속성의 문자열을 비교한다.
.selector-attributes [data-featured] { background: #ffdc66; }
.selector-attributes [type="email"] { border: 3px solid #0057d9; }
.selector-attributes [href^="https://"] { color: #11643a; }
.selector-attributes [href$=".pdf"] { border-bottom: 5px solid #9b3f00; }
.selector-attributes [href*="guide"] { font-weight: 900; }

<p data-featured>이번 주 추천 자료</p>
<label>이메일 <input type="email" placeholder="name@example.com"></label>
<a href="https://developer.mozilla.org/ko/">MDN 웹 문서</a>
<a href="#guide.pdf">PDF 안내 자료</a>
<a href="#guide-start">시작 안내</a>

이번 주 추천 자료

MDN 웹 문서
PDF 안내 자료
시작 안내

PDF 링크는 문자열 비교를 위한 페이지 안 이동 예시이다. 실제 파일 다운로드는 하지 않는다.

시작 안내 링크의 이동 위치이다.

EXAMPLE 5

가상 클래스는 요소의 현재 상태를 조건으로 삼는다

  • :hover: 포인터가 올라온 상태이다. 터치 화면에서는 같은 방식으로 동작한다고 가정하지 않는다.
  • :focus-visible: 브라우저가 포커스 표시가 필요하다고 판단한 상태이다.
    키보드의 Tab 키로 아래 입력창에 이동하면 파란 외곽선이 보인다. 키보드는 포인터가 없으므로 현재 위치를 표시하는 것이 중요하다.
  • :checked: 체크박스·라디오 버튼이 선택된 상태이다.
    input:checked + span은 체크된 input 자체가 아니라 바로 뒤의 span을 꾸민다.
  • :disabled: 실제 disabled 속성으로 조작이 금지된 요소이다.
    회색을 칠하는 것만으로 비활성화되지는 않는다. 기능은 HTML 속성, 모양은 CSS가 담당한다.
.selector-states button:hover:not(:disabled) { background: #bdefff; }
.selector-states input:focus-visible { outline: 3px solid #0057d9; outline-offset: 4px; }
.selector-states input:checked + span { color: #11643a; font-weight: 900; text-decoration: underline; }
.selector-states button:disabled { background: #ece8df; color: #4d5b5f; cursor: not-allowed; }

<button type="button">포인터를 올려 보세요</button>
<label>이름 <input type="text"></label>
<label><input type="checkbox"> <span>알림 받기</span></label>
<button type="button" disabled>사용할 수 없음</button>

마우스로 버튼 위에 올라가고, Tab 키로 입력창에 이동하고, Space 키로 체크 상태를 바꿔 본다.
HTML 내용을 다시 작성하지 않아도 상태에 맞춰 규칙이 적용되거나 해제된다.

EXAMPLE 6

첫째·마지막·짝수 번째를 구조로 구분한다

  • :first-child와 :last-child: 부모의 첫 번째·마지막 요소 자식인지 확인한다.
    li:first-child는 첫 번째 li라는 뜻이 아니라 ‘li이면서 첫 번째 자식’이라는 뜻이다.
  • :nth-child(2n): 형제 요소 전체에서 2·4·6번째처럼 짝수 번째를 선택한다.
    odd 또는 2n+1은 홀수, 3은 세 번째이다. 번호는 1부터 시작한다.
  • :not(.sold-out): 괄호 안 조건에 맞지 않는 요소를 선택한다.
    아래에서는 품절 class가 없는 항목만 굵게 표시한다.
.selector-structure li:first-child { border-left: 8px solid #0057d9; }
.selector-structure li:last-child { border-right: 8px solid #9b3f00; }
.selector-structure li:nth-child(2n) { background: #e4efff; }
.selector-structure li:not(.sold-out) { font-weight: 900; }

<ul>
  <li>첫 번째 항목</li>
  <li class="sold-out">두 번째 · 품절</li>
  <li>세 번째 항목</li>
  <li>네 번째 항목</li>
</ul>
  • 첫 번째 항목
  • 두 번째 · 품절
  • 세 번째 항목
  • 네 번째 항목

두 번째와 네 번째는 같은 배경이지만 두 번째만 보통 굵기이다.
앞에 새 li를 추가하면 뒤 항목의 순서 조건도 달라진다.

EXAMPLE 7

:는 조건, ::는 요소의 일부나 생성된 장식을 나타낸다

  • 가상 클래스 :hover: 이미 있는 요소가 특정 조건을 만족하는지 고른다.
  • 가상 요소 ::before·::after: 요소 내용의 앞·뒤에 CSS로 생성한 장식을 배치한다.
    아래 별표와 체크표시는 HTML의 별도 span이 아니다. content 선언이 장식 문자를 만든다.
  • 내용과 장식 구분: 상태 설명·가격·버튼 이름처럼 중요한 정보는 HTML에 작성한다.
    CSS가 사라져도 의미가 유지되도록 가상 요소는 보조 장식에 사용한다.
.selector-pseudo .note::before { content: "★ "; color: #9b3f00; }
.selector-pseudo .note::after { content: " ✓"; color: #11643a; }

<p class="note">즐겨찾기에 저장됨</p>

즐겨찾기에 저장됨

선택자로 대상을 골랐다면 다음에는 겹치는 규칙 중 어느 선언이 적용되는지 살펴본다.
정확한 선택과 최종값 결정은 서로 다른 단계이다.
